你好，世界：我的第一篇文章

很多人写博客的第一篇都是「你好，世界」。我也没能免俗——毕竟，从这里开始最踏实。

为什么又搭了一个站

市面上的平台很多，但总觉得自己的一块地更自在。想写什么写什么，想长什么样就调成什么样，不用被算法推荐牵着走。

拥有的感觉，比被推荐重要。

这个站是怎么搭的

其实特别朴素：

  • HTML 负责结构，几个页面就够；
  • CSS 负责好看，用了明亮渐变和圆角；
  • 一点点 JS 做滚动动画，让页面不那么死板。

没有框架、没有数据库、没有构建步骤。双击 index.html 就能打开，搬到任何地方都能跑。

接下来

我会把这里当成一个长期的角落：读完的书、学到的东西、偶尔冒出来的想法，都会慢慢放进来。如果你碰巧读到，希望它让你会心一笑。
